# buzzfeed-GWC
A silly BuzzFeed-style quiz that finds out what type of electron you are. Following the JavaScript tutorial from Girls Who Code's web design course.

This version only has 2 types of electrons and only 3 questions :<
- an excited-state electron (has so much energy and likes high-energy activities)
- a ground-state electron (already happy with their state--- likes their home and things that are familiar to them?)
